# Earth textures

`2k_earth_daymap.jpg` and `2k_earth_clouds.jpg` by Solar System Scope,
https://www.solarsystemscope.com/textures/ . Licensed under Creative Commons
Attribution 4.0 International: https://creativecommons.org/licenses/by/4.0/ .

Downloaded without modification from that page's 2K Earth day and clouds
links on 2026-10-10. Solar System Scope describes its Earth maps as based on
NASA Blue Marble, adjusted to match geographic coordinates. These are static
context textures; clouds are not current weather. The runtime applies lighting
and a cloud transparency layer. No NASA affiliation or endorsement is implied.
